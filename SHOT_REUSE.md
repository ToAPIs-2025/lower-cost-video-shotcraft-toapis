# Reuse the generated assets

Read [the original spotlight-hero-card recipe](https://github.com/Vincentwei1021/video-shotcraft/tree/13c74a707786872a18e3317e48c5c94011027620/references/shots/opening/spotlight-hero-card.md) and [its exact source](https://github.com/Vincentwei1021/video-shotcraft/tree/13c74a707786872a18e3317e48c5c94011027620/demos/opening/spotlight-hero-card/SpotlightHeroCard.tsx) before integrating. The upstream scene is 172 frames at 30 fps. It uses original page textures and layout coordinates, so a square product image is not a drop-in replacement for every texture.

This repository supplies an asset manifest, original bytes and model comparisons. Create your own real product page/card captures and matching layout before integrating. No original Remotion component render or whole-film acceptance is claimed.
